# Constellate technology audit

Audited on 2026-10-06 against the actual [keibored/constellate repository](https://github.com/keibored/constellate/tree/10c0714c76d513dc66dddb33997c68a892cad71c), snapshot `10c0714c76d513dc66dddb33997c68a892cad71c`. The complete repository tree is not truncated and contains no AGENTS.md. Portfolio dependencies and design plans were not used as stack evidence.

## Confirmed stack

| Technology | Dependencies and implementation |
| --- | --- |
| React | [client/package.json](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/client/package.json) declares react/react-dom; [client/src/main.tsx](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/client/src/main.tsx) renders the React app and AuthProvider. |
| TypeScript | client/package.json and [server/package.json](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/package.json) declare TypeScript; both build scripts compile it. [client/tsconfig.app.json](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/client/tsconfig.app.json), [server/tsconfig.json](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/tsconfig.json), and actual .ts/.tsx files confirm use on both sides. |
| Node.js | [package.json](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/package.json) specifies Node engines and starts server/dist/index.js with node. [server/src/app.ts](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/src/app.ts) imports node:http/node:crypto; [server/src/index.ts](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/src/index.ts) starts the HTTP server and registers process shutdown handlers. |
| Express | server/package.json declares express; server/src/app.ts imports it, calls express(), installs middleware, and mounts actual API routes. |
| Socket.IO | client/package.json declares socket.io-client; [client/src/services/socket.ts](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/client/src/services/socket.ts) creates the typed socket connection. server/package.json declares socket.io; [server/src/socket/sharedRoom.ts](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/src/socket/sharedRoom.ts) creates the server and handles room joins, timers, presence, chat, reactions, and voice signaling. This shared handler is called by app.ts, which is called by index.ts. |
| Supabase | client/package.json declares @supabase/supabase-js; [client/src/services/supabase.ts](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/client/src/services/supabase.ts) creates the auth client when configured. [AuthProvider.tsx](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/client/src/features/auth/AuthProvider.tsx) reads/subscribes to sessions; [AuthPage.tsx](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/client/src/features/auth/AuthPage.tsx) implements sign-up and password sign-in. [server/src/services/supabaseAuth.ts](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/src/services/supabaseAuth.ts) verifies access tokens through Supabase Auth and is wired into index.ts. The confirmed role is authentication; this is not evidence that Supabase hosts the PostgreSQL database. |
| PostgreSQL | server/package.json declares pg. [server/src/db/pool.ts](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/src/db/pool.ts) creates pg.Pool. [server/src/startup.ts](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/src/startup.ts) requires DATABASE_URL and verifies migrations before startup. index.ts constructs PostgreSQL repositories. [postgresRoomRepository.ts](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/src/repositories/postgresRoomRepository.ts) executes real SQL for room/task/account data; [server/db/migrations/001_create_rooms.sql](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/db/migrations/001_create_rooms.sql) and [002_create_tasks.sql](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/db/migrations/002_create_tasks.sql) define persistent tables. |
| Redis | server/package.json declares ioredis and @socket.io/redis-adapter. [server/src/redis/connection.ts](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/src/redis/connection.ts) constructs Redis command/pub/sub clients; startup.ts requires REDIS_URL and connects them. index.ts constructs RedisRoomRuntime. [server/src/redis/roomRuntime.ts](https://github.com/keibored/constellate/blob/10c0714c76d513dc66dddb33997c68a892cad71c/server/src/redis/roomRuntime.ts) reads/writes shared state using Redis commands/Lua; sharedRoom.ts installs the Redis Socket.IO adapter and uses the runtime for room/timer/presence events. |

Redis and PostgreSQL are included because current runtime wiring, queries, and state operations exist, not because planning documents mention them. Supabase authentication is configuration-dependent; guest rooms remain supported. These findings establish the implementation at the audited revision, not the live deployment's secret configuration or a newly executed integration test.
